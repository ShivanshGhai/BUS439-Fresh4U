# Fresh4U labour planner

A prototype for **Fresh4U** (BUS 439, Simon Fraser University, Fall 2026 · Team BCGLW).
It turns Priva Performance exports into a weekly labour plan, a supervisor's crew-strengths view
and a weekly list of registrations to check — and refuses any data it cannot verify.

> **No client data is in this repository.** The demo runs on clearly labelled SYNTHETIC exports
> generated by `scripts/make_demo_data.py`. Real Priva exports stay on Fresh4U's and the team's machines.

## What it does

| Part | Question it answers | How |
|---|---|---|
| **Pipeline** (`run.py`, `fresh4u/`) | Can we trust the numbers? | Reads each Priva export by its headers, checks every record against Priva's own daily and grand totals, loads only files that pass, quarantines the rest with a plain reason. Re-exports replace their period; duplicates are ignored. |
| **Weekly planner** | How many people does a task need next week? | rows to do × recent minutes per row ÷ 60 = hours; ÷ hours per person = people. Back-tested on past weeks. |
| **Crew strengths** | Who is strong at which task? | Speed vs the same task in the same week, shown as bands (Strong / Typical / Developing / Ramping up), never ranks; minimum data before anyone is banded. |
| **Review list** | Which registrations look wrong? | Registrations taking 3×+ the usual time per row (likely missed tag-out), hours with no area or location, impossible areas, duplicates. |

On the 14 real exports (Jan–Aug 2026, 68,190 registrations, 37,206 hours) all 510 Priva totals reconcile,
and the planner's method lands within about 6–16% of actual weekly hours per task.

## Run it

```bash
pip install -r requirements.txt

# the app (demo data, or upload exports)
streamlit run streamlit_app.py

# the pipeline on a folder of real exports (originals are only read)
python3 run.py --inbox "path/to/Priva exports" --data data --out outputs

# tests (standard library only)
python3 -m unittest discover -s tests -v
```

## Repository layout

```
streamlit_app.py        the app (thin UI over fresh4u/)
run.py                  pipeline command
fresh4u/
  priva_reader.py       header-driven reader + reconciliation
  mappings.json         Priva header names -> our field names, per report type
  store.py              history, ingest log, quarantine
  enrich.py             flags, derived metrics, output tables
  planner.py            weekly planner
  coaching.py           crew strengths bands
  app_data.py           runs the pipeline for the app
scripts/make_demo_data.py   synthetic Priva-style exports
demo_data/              the synthetic exports (one hand-edited on purpose)
tests/                  regression, robustness, planner/coaching, app smoke test
docs/PIPELINE.md        pipeline details and safety rules
```

## Status and limits

- Prototype for client feedback, not a production system.
- Budget/planned hours, harvest data and quality are not in the exports yet.
- Row 1xxx = House 1 and 2xxx = House 2 is an assumption to confirm.
- Crew strengths measure speed only, for supervisors; they are not a basis for pay or discipline.
